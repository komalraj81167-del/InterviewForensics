# InterviewForensics

AI-powered interview rejection analysis and personalized candidate coaching system.

## Problem

Candidates often receive little or no useful feedback after an unsuccessful interview.

InterviewForensics analyzes interview sessions to identify potential weaknesses in:

- Speech patterns
- Answer structure
- Clarity
- Relevance
- Depth
- Specificity
- Technical explanations
- Behavioral responses

## Planned Features

- Interview recording upload
- Speech-to-text transcription
- Filler word detection
- Pause and pacing analysis
- Answer quality evaluation
- STAR analysis
- Technical answer evaluation
- Job description matching
- Weakness ranking
- Personalized improvement plan
- Interview performance dashboard
